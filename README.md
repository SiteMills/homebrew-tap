# SiteMills Homebrew Tap

```bash
brew install sitemills/tap/sitemills-cli
```

Upgrade with `brew upgrade sitemills-cli`. See the [SiteMills CLI](https://github.com/SiteMills/sitemills-cli) for documentation and other install options.

**Do not commit to this repository directly.** `Formula/sitemills-cli.rb` is generated and published by the SiteMills CLI release tool on every release.
